# 🚀 Início Rápido - Agendamento Premium

## ⚡ Primeiros Passos (3 minutos)

### 1️⃣ Abrir o Aplicativo
- Clique em "Open Preview" ou acesse o link do projeto
- O app abrirá com dados de exemplo já carregados

### 2️⃣ Explorar as Funcionalidades

#### 📊 Dashboard
- Veja o resumo do dia com agendamentos e faturamento
- Confira os próximos agendamentos
- Verifique alertas de estoque
- Veja clientes com débitos

#### 👥 Clientes
- Clique em "Clientes" no menu lateral
- Clique em qualquer cliente para ver detalhes completos
- Botão "+ Novo Cliente" para adicionar

#### 📅 Agenda
- Acesse "Agenda" no menu
- Escolha visualização: Dia, Semana ou Mês
- Botão "+ Novo Agendamento" para agendar serviços ou eventos
- Navegue entre datas com as setas

#### 💉 Serviços
- Veja todos os serviços cadastrados
- Cada card mostra: tipo, valor, duração
- Clique para editar

#### 📦 Estoque
- Produtos com alertas de estoque baixo aparecem destacados
- Botão "+ Novo Produto" para adicionar

#### 📈 Relatórios
- Selecione mês e ano
- Veja gráficos de faturamento e quantidade
- Tabela detalhada por cliente
- Botão "Exportar PDF" para impressão

### 3️⃣ Instalar no iPhone

1. Abra no **Safari** (importante!)
2. Toque no botão de compartilhar 📤
3. Role e selecione "Adicionar à Tela de Início"
4. Pronto! Agora é um app nativo 🎉

## 💡 Dicas Úteis

### Adicionar Mais Dados de Exemplo
Se quiser mais dados para testar:
```
Acesse: /?popular=true
```

### Buscar e Filtrar
- Use a barra de busca em cada seção
- Digite nome, telefone ou tipo para filtrar

### Atalhos de Teclado
- `F12` - Abrir console (para desenvolvedores)
- `Ctrl+P` / `Cmd+P` - Imprimir relatórios

### Marcar Débito como Pago
1. Vá em Dashboard > "Clientes com Débitos"
2. Ou abra o cliente e vá na aba "Débitos"
3. Clique em "Marcar como Pago"

### Status dos Agendamentos
- 🟢 **Pago** - Cliente já pagou
- 🟡 **Pendente** - Aguardando pagamento
- 🔴 **Devendo** - Cliente deve o valor

## ❓ Perguntas Frequentes

### "O app está em branco"
- Recarregue a página (F5)
- Limpe o cache do navegador
- Acesse `/?popular=true` para carregar dados

### "Não consigo adicionar à tela inicial"
- Use Safari (obrigatório para iOS)
- Certifique-se de que está em HTTPS
- Siga exatamente os passos acima

### "Os gráficos não aparecem"
- Selecione um mês que tenha serviços realizados
- Verifique se há dados concluídos no período

### "Quero resetar tudo"
```javascript
// Cole isso no console (F12) e dê Enter:
localStorage.clear();
location.reload();
```
